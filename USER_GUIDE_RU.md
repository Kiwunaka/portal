# Portal: Руководство пользователя (RU)

Обновлено: `2026-02-15`

## 1) Быстрый старт

1. Откройте бота `@portal_service_bot`.
2. Нажмите кнопку продления/подключения.
3. Выберите способ оплаты:
   - `Оплатить ₽` (основной);
   - `Оплатить Stars` (альтернативный).
4. После оплаты откройте кабинет и проверьте статус.

## 2) Тарифы

- `Start 99`:
  - `99 ₽`
  - `30 дней`
  - `1 устройство`
  - профиль с маршрутом NL
- Далее доступны планы на `1/3/6/9/12` месяцев.

## 3) Оплата в рублях на сайте

Сайт использует безопасный backend-first flow:

1. Переходите из бота в checkout.
2. Сервер создаёт заказ.
3. Открывается платёжная страница провайдера.

Если вы открыли checkout без привязки к Telegram-аккаунту, сайт предложит перейти в бота и получить корректную ссылку.

## 4) Промокоды

Поддерживаются форматы deep link:

- `https://t.me/portal_service_bot?start=promo_CODE`
- `https://t.me/portal_service_bot?start=campaign_NAME__promo_CODE`

Типы промо:
- `days`: дни добавляются сразу.
- `discount`: скидка применяется к следующей покупке.

## 5) Канал проекта и бонус

В кабинете доступна кнопка `Статус подписчика — Проверить`.

Что это даёт:
- подтверждение подписки;
- разовый бонус баллами;
- для free-профиля снимается базовый speed-bump.

## 6) Подключение на устройствах

- Android: deep-link в `v2rayNG` + fallback в `Hiddify`.
- iOS: путь через `Streisand/Happ` и инструкцию в кабинете.
- Desktop: копирование ключа и ручной импорт по инструкции.

## 7) Если платёж не прошёл

1. Повторите попытку из checkout.
2. Проверьте, что открываются страницы:
   - `/pay/success` после успешной оплаты;
   - `/pay/fail` при отказе.
3. Если статус не обновился, напишите в поддержку и приложите `order_id`.

## 8) Безопасность

- Не передавайте персональную ссылку подключения третьим лицам.
- Используйте только официальные ссылки из бота, сайта и канала проекта.
