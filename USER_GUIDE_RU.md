# Portal: руководство пользователя (RU)

Обновлено: `2026-02-14`

## 1. Быстрый старт

1. Откройте бота `@portal_service_bot`.
2. Нажмите `⚡ Зарядить`.
3. Выберите способ оплаты:
   - `Оплатить ₽` (основной способ),
   - `Оплатить Stars` (альтернативный способ).
4. После оплаты откройте личный кабинет и получите ссылку подключения.

## 2. Тарифы

- `Start 99`:
  - `99 ₽`
  - `30 дней`
  - `1 устройство`
  - стартовый профиль по NL.
- Дальше доступны расширенные планы `1/3/6/9/12` месяцев.

## 3. Промокоды и ссылки

Поддерживаются авто-промо ссылки формата:

- `https://t.me/portal_service_bot?start=promo_CODE`
- `https://t.me/portal_service_bot?start=campaign_NAME__promo_CODE`

Если код валиден, он применится автоматически (с учетом лимитов использования).

## 4. Канал проекта и бонусы

В личном кабинете есть блок статуса подписки на канал:

- Нажмите `Статус подписчика — Проверить`.
- За подтвержденную подписку начисляется разовый бонус `+100 points`.

Для free-профиля это также снимает базовое ограничение скорости (soft speed-bump).

## 5. Что делать, если оплата не прошла

1. Повторите попытку из checkout.
2. Проверьте, что открывается страница:
   - `.../pay/success` после успешной оплаты,
   - `.../pay/fail` при отмене/ошибке.
3. Если статус не обновился, напишите в поддержку, приложив `order_id`.

## 6. Частые вопросы

### Где лучше платить?

- В большинстве случаев удобнее `Оплатить ₽` через checkout.
- Stars можно использовать как резервный/альтернативный вариант.

### Почему у меня базовая скорость?

- Для free-профиля без подтвержденной подписки на канал действует мягкое ограничение.
- Подтвердите подписку через кнопку проверки в кабинете.

### Как узнать, что промокод применился?

- Бот покажет сообщение о результате применения.
- В кабинете обновятся условия/срок, если код дал бонус.

## 7. Безопасность

- Никому не передавайте вашу персональную ссылку подключения.
- Используйте только официальные ссылки из бота, сайта и канала проекта.
