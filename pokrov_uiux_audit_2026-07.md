### Сквозные находки (важнее любой отдельной поверхности)

1. **P0 СИСТЕМНОЕ: фирменный шрифт Golos Text не загружается ни на лендинге, ни в кабинете.** Ни `next/font`, ни `@font-face`, ни файлов шрифта нет ни в `marketing/`, ни в `webapp/` — только мёртвая строка `--font-golos: "Golos Text"` (`marketing/src/app/globals.css:39`, `webapp/src/app/globals.css:98`). Весь веб-эстейт рендерится в **Segoe UI / system-ui**. Прямое нарушение DESIGN.md («CSS-only font references are forbidden»). Это самый большой разрыв между задуманным брендом и тем, что видит пользователь, — и чинится он одним изменением на поверхность.
2. **`text_muted` (#9aa1a9, ~2.6:1) используется для читаемого текста на обеих веб-поверхностях** — по канону он decorative-only. Хуже всего то, что им набраны objection-handling тексты в моменты решения (email/промокод на чекауте, SmartScreen-заметка на /install/).
3. **Хорошая новость: моушен-система на вебе уже на уровне.** Единый apple-ease `cubic-bezier(0.22,1,0.36,1)`, спринги где надо, transform/opacity-дисциплина, почти полное покрытие `prefers-reduced-motion`. Ломать нельзя — только достраивать.
4. **`pokrov_uiux_master_plan.md` частично устарел против DESIGN.md 2026-07**: «Atlas Glass» (стекло, glow, glass-panels) противоречит канону «pokrov-clear» (стекло на контентных слоях retired). Mojibake из плана уже вычищен (обе поверхности чистые — проверено). Плану нужна пометка о статусе, иначе следующий агент снова начнёт строить стекло.
5. **Telegram: 20 июля 2026 автоматически включается origin-защита Mini Apps** (Bot API 10.2, 14 июля 2026). Плюс сам файл `webapp/public/telegram-web-app.js` — load-bearing, но не закоммичен (untracked): свежий чекаут/CI собирает кабинет **без** Mini App-моста.

Тупиков нет.

### Находки

- **P1-1. `text_muted` на читаемом тексте**: `platform-tabs.tsx:89` (SmartScreen/legacy-нота), `pricing.tsx:90`, `checkout-client.tsx:523,540,636,658` («Email нужен для чека и кода активации…» — критично для покупки), `footer.tsx:20,92`, `seo-content-page.tsx:146`.
- **P1-2. В мобильной шапке нет CTA**: «Кабинет»/«Скачать» — `hidden … md:flex` (`topbar.tsx:60`); на мобиле главное действие спрятано за бургером. Для Android-аудитории это крупнейший чистый conversion-gap.
- **P1-3. Ноль соцдоказательств** на всей воронке; `buildSoftwareApplicationJsonLd` уже поддерживает `reviews` (`lib/marketing-site.ts:327-343`), но не используется. Канон запрещает только *непроверяемое*.
- **P1-4. Разрыв ожиданий на скачивании**: кнопки «Скачать…» ведут в кабинет в новой вкладке (`install/page.tsx:27-32,176-181`), а не к файлу; момент «кнопка говорит скачать — открылся кабинет» не объяснён в точке клика.
- **P2**: showcase-пин 360vh (лучше ~70vh/слайд) и `<h3>` внутри `<button>` (`showcase-scroller.tsx:77,96`); фокус-кольца непоследовательны (аккордеон, бургер, навлинки, чекаут-селекторы — UA-default); `.reveal { opacity:0 }` в SSR — без JS всё ниже hero невидимо; бейджи каталога («-45%», «Популярный») замаплены, но нигде не рендерятся (`checkout-client.tsx:328`); каждый клик по тарифу перефетчивает каталог (`checkout-client.tsx:312-343`); в FAQ нет вопроса про приватность/логи — объекция №1 категории; typography-токены `--pokrov-font-size-*` не потребляются (всё захардкожено); нет `env(safe-area-inset-*)`; framer-motion в бандле каждой страницы (нужен `LazyMotion`).

### Топ-5 по влиянию на конверсию

1. Подключить Golos Text через `next/font/google` (latin+cyrillic, 400–800).
2. Компактная pill-кнопка «Скачать» в мобильном topbar.
3. `text-ink-muted` → `text-ink-soft` во всех точках P1-1.
4. Проверяемое соцдоказательство у Pricing/FinalCta (версия+дата релиза с GitHub, checksums, отзывы через `reviews`).
5. Показ «-45%» на карточках года + объяснение перехода в кабинет на download-CTA.

## 3. Апка — `POKROV-app` (Flutter, Android + Windows)

### Что уже хорошо (не ломать)

- **Дисциплина токенов с контракт-тестами, фиксирующими hex/длительности/хаптики/геометрию диска** (`test/design_system_contract_test.dart:21-55`: accent `0xFF12805A`, connectedGreen `0xFF34C759/0xFF30D158` — канон точь-в-точь). Редкость и золото.
- **Orb-хореография коннекта — лучшая часть продукта** (`shell_widgets.dart:138-674`): idle-пульс → connecting: вращающаяся дуга 0.86π @1250ms + 0.985 scale → connected: iOS-зелёный, «дыхание» ±1.4% @1800ms, medium-impact хаптик → error: warning-ring + heavy impact; press 0.97 / spring release; `RepaintBoundary`; reduced-motion фолбэки.
- **Единая iOS-грамматика на всех платформах**: Cupertino-переходы страниц, BouncingScrollPhysics + снятый Android-glow, подавленный ripple в пользу scale, настоящий `CupertinoSwitch` с `#34c759`, sheets с drag-handle и 28px радиусом, 44px чипы / 50px кнопки.
- Честность: скелетоны вместо спиннеров, реальный поллинг runtime каждые 450ms, WARP-копирайт честно-отложенный, fake progress — 0. Golos Text 400–800 бандлится (latin+cyr, OFL). Android 90/120Hz анлок; Windows — тёмный тайтлбар, трей, Ctrl+1–4.

### Находки

- **P0-1. Иконка Android — legacy-only**: нет `mipmap-anydpi-v26`, adaptive/monochrome слоёв — на всех современных лаунчерах POKROV выглядит ужатой иконкой в белом круге. Самый громкий «не premium» сигнал ДО открытия приложения.
- **P0-2. Дисконнект показывает «Подключается...»**: `runtimeBusy` замыкает и лейбл действия, и статус на коннект-копирайт (`home_surface.dart:73-79,1111-1112`) на всё время сеттла (~4.5s). Стейт-машина `disconnecting` в `pokrov_connect_disc.dart:10` есть — слой копирайта её не использует. Нарушение «честных состояний».
- **P0-3. Windows: ✕ убивает приложение при живом трее**: `main.cpp:33` `SetQuitOnClose(true)`, `setPreventClose` не вызывается. Трей-VPN, умирающий по крестику, ощущается веб-обёрткой. Плюс: нет min-size, окно всегда в `(10,10)`, размер не персистится.
- **P1**: нет edge-to-edge/`SystemChrome` (плавающий tab bar сидит над стоковым системным баром); generic пустой splash (нет Android 12 SplashScreen API с брендом); predictive back не включён в манифесте (код уже `PopScope`-ready); единственный Material-диалог — стоковый `AlertDialog` апдейта («Позже»/«Скачать», `seed_shell.dart:856-890`) ломает иллюзию в высоковидимый момент; хаптика двоемозгая — 13 сырых `HapticFeedback.selectionClick()` мимо обёртки `PokrovHaptics`, нет тика на таб-свитч и на завершение дисконнекта; `api.pokrov.space` светится в консюмерском тексте («Настройки обновлены с …», `seed_shell.dart:1649`); busy-строки локаций выглядят живыми, но мертвы (без dimming/IgnorePointer, `locations_surface.dart:467,566`).
- **P2**: «спринги» — фейковые кубики (`Cubic(0.34,1.36,0.64,1)`, `pokrov_motion.dart:43`) без наследования скорости как в UIKit; выбор в desktop-сайдбаре снапается без анимации (`pokrov_sidebar.dart:185-191` + мёртвый `AnimatedOpacity`); три диалекта статуса («Подключается…»/«Подключаемся»/«POKROV включен.»); тема-шит закрывается по сырому `Timer(320ms)` мимо MotionScope; `_HomeStatusAction` — единственный таргет без scale-фидбека; трей-пункт «Поддержка» просто фокусирует окно; два параллельных карточных API (`_SectionCard` vs `PokrovSurface`).

### Топ-5 по ощущению «нативно»

1. Adaptive + monochrome иконка Android (anydpi-v26) — первое впечатление на каждом хоумскрине.
2. «Отключаем...» через существующую фазу `disconnecting` + отдельный хаптик на возврат в idle.
3. Windows tray-first: `setPreventClose` → скрытие в трей по ✕ (с одноразовым снеком), центрирование, min 980×640, персист позиции.
4. Edge-to-edge + брендовый Android 12 splash, переходящий в 480ms home-reveal.
5. Хаптики через одну обёртку + замена апдейт-диалога на фирменный sheet.

## 4. Бот — `portal_bot/` (слабейшая поверхность, диагноз подтверждён)

Архитектура: aiogram (venv: **3.24.0**, Bot API 9.3; requirements `>=3.23`), long-polling, edit-in-place навигация (хорошо), политика «одно видимое сообщение» + автоудаление всего через 24ч, копи-каталог с governance-метаданными (но покрывает меньшинство строк — большинство захардкожено в `bot.py`, 11k строк). Parse mode — **legacy Markdown 2019 года** почти везде; в worker/тикетах — вообще без форматирования.

### P0 — ломают деньги и главный цикл

1. **Все retention/abandoned-cart пуши ведут на `?start=pay`, который никем не обрабатывается** (`worker.py:154-155,640,889`; в `cmd_start` ветки нет, таблица `start_links` пуста). Клик с максимальным интентом («Оплатить / Продлить») высаживает юзера на generic «С возвращением!» в двух экранах от оплаты. Фикс — одна ветка `if start_arg == "pay": → экран тарифов`.
2. **Коммерция бота — тупик при текущих флагах, а CTA продолжает кричать «💳 Продлить или начать»**: `_bot_checkout_blocked_reasons` (`bot.py:3348-3358`) требует `PAID_CHECKOUT_LAUNCH_APPROVED` + `CHECKOUT_TICKET_SECRET`, которых нет → каждый тариф кончается «Оплата пока закрыта». Меню обязано рендерить доступность честно (проверяемо в рантайме).
3. **Пост-оплата самоуничтожается, а выжившая кнопка ведёт на сырую ссылку**: успех → «Доступ готов!» → квитанция, при этом каждое следующее сообщение удаляет предыдущее (`_track_context_message`, `bot.py:415-439`) — остаётся только квитанция «249 XTR… TransID… Лицензия активирована», чья единственная кнопка `✅ Готово` = `show_key` (raw subscription URL) — против app-first. И квитанция тоже испарится через 24ч.
4. **«📋 Скопировать ссылку» не может ничего скопировать**: `callback.answer(..., show_alert=True)` (`bot.py:4252-4257`) — алерты в Telegram некопируемы. При этом `copy_text`-кнопка (Bot API 7.11) поддерживается и стеком, и собственным хелпером (`telegram_buttons.py:31,79-80`) — ноль вызовов.

### P1 — видимо бьют по качеству/доверию

- **Грамматика тикетов сломана механической заменой «тикет»→«обращение»**: «Обращение не найден», «Нет доступа к обращениеу», «У тебя уже есть активный обращение», «Обращениеов пока нет», «Очередь обращениеов» (`bot.py:6333-6663`). В helpbot та же логика написана грамотно — две планки качества в одном продукте.
- **ты/вы вперемешку** в одном журнале: «Выберите, что сделать» рядом с «Ты на волне», «Купи карту → отправь другу!», «Тебе выпало: +7 Дней!» (~15 строк).
- **Тарифные кнопки: двойные эмодзи + скобки в скобках → обрезаются на телефонах**: `⚡ ⚡ Приветственный 30 дней — 99 ₽ (старт)`, `👑 📅 12 Месяцев — 1644 ₽ (максимум выгоды, -45%)` (~49 символов при обрезке с ~30) — цена и скидка отваливаются первыми (`bot.py:3545-3592`).
- **Инференс стилей кнопок красит навигацию в красное**: substring-эвристика `back/cancel/close → DANGER` (`telegram_buttons.py:44-61`) — каждый «◀️ Назад» рендерится деструктивно-красным, а дефолт PRIMARY на всё остальное убивает иерархию.
- **Три противоречивые истории про fallback-приложения одному юзеру**: каталог говорит «Karing или Happ», хардкоды/FAQ — «начните с Hiddify… ?format=happ» (`catalog.ru.json:313,340` vs `bot_texts.py:77-86`, `bot.py:4246,4991`). Плюс query-string синтаксис в first-layer онбординге.
- **Фейковая диагностика против «calm honest»**: «⚡️ Нагрузка системы: N%» — это счётчик клиентов, а не проценты; фейковое «Сканирование узлов…» ничего не сканирует; «Сервер: ✅ Онлайн» захардкожен (`bot.py:6120-6147,6273`).
- **Валютная шизофрения**: продаём в ₽, квитанция в XTR, worker предлагает «1 месяц за 149 Stars» при выключенных Stars (`bot.py:9484`, `worker.py:888`).
- QR-фото приходит **без клавиатуры вообще**, удаляя предыдущее сообщение со ссылкой (тупик); статус-карта мешает КАПС «АКТИВЕН», внутренности «(база 5 + family 1)» и сырой `TRIAL_5D`.

### P2 (выборка)

Триал спрятан на 4-5 тапов от /start (главный крючок продукта не на первом экране); интерстишл канал-бонуса перехватывает навигацию; нет `/help` и фолбэка на неизвестные команды; эмодзи-непоследовательность (голые «Проверить доступ», «Помощь»); pending-стейт в памяти (рестарт молча съедает следующий месседж юзера); мёртвый A/B (оба варианта CTA идентичны); геймификация «Sentinel/Phantom/Lucky Glitch/ДЖЕКПОТ!!!/Сбой матрицы» — казино-голос внутри calm-premium бренда; referral share-URL не энкодится; `/gift trial` = 7 дней при продуктовых 5.

### Что уже хорошо

Edit-in-place навигация + `answerCallbackQuery` в ~95% мест; персистентная WebApp-кнопка меню «POKROV» → app.pokrov.space; движок диплинков (referral/gift3/promo/campaign) с честными конфликт-статусами; надёжная пейментная сантехника (дедуп, идемпотентность, back-compat парсер); тёплый копирайт флагманских экранов («Давайте без терминов», «Деньги не теряются: по чеку мы находим платёж»); graceful-даунгрейд в FREE вместо отключения; PROTECTED_USERS и fail-closed проверки.

## 5. Новые апдейты Telegram Bot API (то самое «rich markdown»)

Свежий changelog (получен с core.telegram.org 2026-07-14):

| Версия | Дата | Что важно для POKROV |
| --- | --- | --- |
| **10.2** | **14.07.2026** | Rich Messages v2: `InputRichMessageMedia` (медиа прямо в markdown/html rich-сообщениях), список-блоки; **Ephemeral Messages**; Communities; `BotSubscriptionUpdated`; ⚠️ **hardening origin-защиты Mini Apps — автовключение 20.07.2026** |
| **10.1** | 11.06.2026 | **Rich Messages** — `sendRichMessage` / `sendRichMessageDraft` (стриминг!): заголовки секций, **таблицы**, **сворачиваемые Details**, цитаты/pull-quotes, разделители, футеры, коллажи, слайдшоу, карты, якоря, mathe­matical expressions; `rich_message` в `editMessageText` |

| 9.6 | 03.04.2026 | Managed bots, квизы с несколькими ответами |

| 9.4 | 09.02.2026 | **Официальные `style` (цвет) и `icon_custom_emoji_id` у кнопок**, кастом-эмодзи в сообщениях бота (при Premium у владельца), топики в личках, `setMyProfilePhoto` |
| 9.0–9.3 | 2025 | `DeviceStorage`/`SecureStorage` в Mini Apps, `hideKeyboard`, стриминг `sendMessageDraft` (9.3), `message_effect_id`, checklists |

**Стек бота против этого**: в venv aiogram **3.24.0 = Bot API 9.3**. На PyPI — **aiogram 3.29.1 = Bot API 10.1**, т.е. Rich Messages доступны уже сейчас апгрейдом зависимости (10.2 подтянется следующим релизом aiogram). `telegram_buttons.py` уже пробует `style`/`icon_custom_emoji_id`/`copy_text` — инфраструктура готова, дизайна нет.

### Что внедрить в бота (по убыванию ценности)

1. **Апгрейд aiogram → 3.29.1** и перевод текстов с legacy Markdown на HTML/entities централизованно (в `_send_text_with_specs`/`_edit_text_with_specs`), с экранированием интерполяций.
2. **Rich Messages** для флагманских экранов: тарифы — **таблица** (срок/цена/выгода вместо 49-символьных кнопок); FAQ и инструкции — **Details (сворачиваемые секции)**; квитанция — section heading + таблица + footer; стриминг `sendRichMessageDraft` для AI-ответов helpbot.
3. **`copy_text`-кнопка** для ручной ссылки (лечит P0-4 одним параметром) + `protect_content` на сообщениях с личной ссылкой/QR.
4. **`date_time`-entity** для «Доступ до …» (локализованное время юзера — мелочь с premium-ощущением).
5. **Осмысленные стили кнопок** (9.4): DANGER только panic/delete, «Назад» нейтральный, один PRIMARY на экран — заменить substring-эвристику явным `style=`.
6. **`message_effect_id`** на успех оплаты/бонуса; **реакции** как дешёвый ack на присланный код; `sendChatAction("typing")` вместо фейковых sleep-редактов.
7. **Mini App**: проверить origin-настройку до 20.07.2026; MainButton/SecondaryButton; `selectionChanged`-хаптика; `SecureStorage` для токенов кабинета.
