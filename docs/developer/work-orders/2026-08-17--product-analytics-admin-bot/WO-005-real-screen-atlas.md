# WO-005 — Real Screen Atlas

Status: `COMPLETED`

The Android atlas now contains 22 real current screens. Old landscape mockups
for diagnostics, account, support, protection, restore, rewards, DNS, presets,
custom rules, Wi-Fi, system VPN settings, subscription, theme and notifications
were replaced with inspected public `1.1.1` captures. App picker and support
chat were added as their own entries.

Hotspots were remapped to the portrait controls and image intrinsic dimensions
were corrected. Evidence omits account IDs, codes, IPs, keys, subscription URLs
and payment data.
