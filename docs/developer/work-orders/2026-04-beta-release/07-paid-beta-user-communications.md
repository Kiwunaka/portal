## Usage Rule

Do not send the opening or payment messages while signoff is `blocked`.

Safe to send now only if needed:

- maintenance or pause message
- beta waitlist/full message
- support guidance for existing testers

## Telegram Paid Beta Announcement

```text
POKROV готовится к закрытой платной бете.

Это не публичный релиз и не магазинная версия. Мы откроем доступ только по приглашениям и не больше чем для 25 участников.

В бете будут Android и Windows. Android доступен только как внутренний APK. Windows может показывать предупреждение Microsoft Defender SmartScreen, если сборка еще не подписана.

Мы сообщим отдельно, когда оплата и загрузки будут открыты. Пока ничего оплачивать не нужно.
```

## Payment Opened Announcement

Use only after payment provider/webhook proof or explicit manual-risk acceptance.

```text
Платная бета POKROV открыта для приглашенных участников.

Как начать:
1. Откройте личный кабинет: https://app.pokrov.space/
2. Выберите доступный тариф для беты.
3. Оплатите и активируйте доступ в кабинете или приложении.
4. Скачайте сборку только из кабинета.

Если после оплаты доступ не появился автоматически, не оплачивайте повторно. Напишите в поддержку через кабинет или @pokrov_supportbot, мы проверим платеж вручную.
```

## Android Internal APK Warning

```text
Android-сборка POKROV сейчас доступна только для внутренней беты.

Это не публичный релиз и не версия из Google Play. Устанавливайте APK только из личного кабинета и только если вы участвуете в бете.
```

## Windows Unsigned Warning

```text
Windows-сборка POKROV для беты может быть неподписанной.

При запуске Windows может показать предупреждение Microsoft Defender SmartScreen или неизвестного издателя. Это ожидаемо для закрытой тестовой сборки, но не является публичным релизом.

Скачивайте файл только из личного кабинета. Если сомневаетесь, напишите в поддержку перед установкой.
```

## Support Instruction Message

```text
Если что-то не работает, откройте обращение в личном кабинете: https://app.pokrov.space/

Запрос должен содержать:
- платформа: Android или Windows
- версия приложения
- что вы пытались сделать
- что увидели на экране
- примерное время ошибки

Не отправляйте публично ключи, ссылки подключения, чеки, номера платежей, токены или личные данные. Если кабинет недоступен, напишите в @pokrov_supportbot.

Цель поддержки в бете: ответить в течение 24 часов, без обещания круглосуточного SLA.
```
