# Bot Admin

Admin is identified by `ADMIN_ID`.

## Health

- `/health` or Admin UI button.

## Broadcast

- Есть 2 режима:
- `🧩 Конструктор рассылки` (рекомендуется): можно отправить боту готовое сообщение (текст/медиа), и он возьмёт его как черновик. Дальше выбираешь сегмент и жмёшь «Отправить».
- `✍️ Текстовая рассылка (legacy)`: старый режим.

Сегменты в конструкторе:
- Активные
- Истекшие
- Free
- Все

### Сообщение одному пользователю

- Через карточку пользователя: `Админка -> Все юзеры -> [пользователь] -> ✉️ Сообщение`.
- После нажатия отправьте одно сообщение (текст/медиа/документ) — бот перешлёт его выбранному пользователю.

## Support Tickets

- Пользовательский вход для тикетов: отдельный support-бот `@portal_privacy_helpbot`.
- Операторская обработка: очередь `🎫 Очередь тикетов` в админке основного бота.
- Технически используется общая БД (`support_tickets`, `support_ticket_messages`), поэтому тикеты видны в одном месте.
