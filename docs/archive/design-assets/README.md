# Retired Design Assets

Classification: `HISTORICAL_REFERENCE / SUPERSEDED`

This directory preserves generated design provenance that is no longer safe or
useful on public product surfaces. It may explain earlier visual decisions, but
it cannot define current copy, product behavior, release status, or promotion
claims.

## Retained Sets

  `marketing/public/` on 2026-07-21. Its account variants include a superseded

  Telegram reward; `up to 10 days` means `5 trial + 5 Telegram reward`.

Do not copy an archived asset back into a public surface without reconciling its
visible text and metadata against current canonical product facts.
