# Bot Admin

Админ-функции управляются **только через основной бот** (`/start` -> `🔒 Админ-панель`).
WebApp не используется как админка.

## Сегментация (источник правды)

- `PAID`: только реально оплаченный доступ.
- `FREE`, `TRIAL`, `BONUS`: freemium/бонусные сегменты (не paid).
- Бонус за канал, trial, подарочные/промо-периоды не переводят пользователя в `PAID`.
- Рулетка доступна только для активного платного пользователя с платежным сигналом.

## Пользовательские базовые правила

- До принятия оферты нельзя выдавать ключ и активировать продление.
- Оферта/политика должны открываться на актуальных URL сайта.

## Промокоды

Путь: `Админ-панель -> 🎟 Промокоды`

Поддерживаются действия:
- просмотр последних кодов;
- создание кода (форма в боте);
- удаление/деактивация кнопкой;
- лимиты использований и срок действия.

Формат создания из формы:
- `CODE|days|14|100`
- `CODE|discount|20|50|2026-03-01T00:00:00`

## Gift-коды

Путь: `Админ-панель -> 🎁 Подарки`

Кнопки:
- `Создать Mini`
- `Создать Standard`
- `Создать Premium`

Формат кода: `PORTAL-XXXX-XXXX`.
Для стабильной генерации используется единый генератор + расширенное поле БД (`gift_cards.code`).

## Последние обновления (Live Updates)

Путь: `Админ-панель -> 📰 Последние обновления`

Создание:
- рекомендуемый формат: `Заголовок|Кратко|@channel|123`
- legacy fallback: `Заголовок|Кратко|https://...`

Логика:
- при `@channel + post_id` собирается `tg_link` вида `https://t.me/{channel}/{post_id}`;
- запись можно включать/выключать;
- поле `link` остается как fallback для старых записей.

## Launch / Start ссылки

Путь: `Админ-панель -> 🔗 Launch ссылки`

Сущность:
- `code`
- `description`
- `target_action`
- `is_active`

Пример публичной ссылки:
- `https://t.me/<bot_username>?start=launch14`

Поддержка API:
- `GET /api/admin/start-links`
- `POST /api/admin/start-links`
- `PATCH /api/admin/start-links/{id}`
- `DELETE /api/admin/start-links/{id}` (мягкая деактивация)

## Рулетка

Путь: `Админ-панель -> 🎰 Рулетка`

Доступно:
- пресеты весов;
- ручной ввод весов (`дни:вес,...`);
- настройка кулдауна.

API:
- `GET /api/admin/wheel-config`
- `PUT /api/admin/wheel-config`

## Групповые действия

Путь: `Админ-панель -> 📊 Групповые действия`

Все массовые операции выполняются через экран подтверждения с количеством затрагиваемых пользователей.

Действия:
- добавить дни активному сегменту;
- отправить напоминание истекающим;
- добавить +14 дней сегменту (в `BONUS`, не в `PAID`);
- синхронизировать пользователей с нодами;
- нормализовать сегменты (`sub_type`).

## Manual users

Путь: `Админ-панель -> 🧩 Manual users`

API продления поддерживает `delta_days` (можно `+` и `-`) с защитой от случайной деактивации.
В карточке пользователя доступны быстрые кнопки `+` и `-` дней.

## Support / Helpbot

Пользовательский вход в поддержку: `@portal_privacy_helpbot`.

Рекомендации:
- использовать `🚀 Начать` как главный CTA;
- приветственное медиа можно включить через env:
  - `HELPBOT_START_MEDIA_PATH`
  - `HELPBOT_START_MEDIA_TYPE` (`photo|animation|video`)
- если медиа недоступно, бот автоматически отправляет текстовый fallback.
