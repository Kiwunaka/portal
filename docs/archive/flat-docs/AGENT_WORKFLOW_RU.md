# Agent Workflow PORTAL

Обновлено: 6 марта 2026

## Роли

- Backend: критические баги, бонусы, payments, API
- Frontend: webapp, marketing, admin UX, link hygiene
- QA: smoke, regression, PASS/FAIL gate
- DevOps: nodes, timers, metrics, deploy chain
- Marketing: copy packs и CTA

## Формат передачи задач

Каждый агент оставляет мини-отчёт:
- Что проверил
- Что нашёл
- Что сделал
- Как проверил
- Что осталось

## Обязательные артефакты

- код/скрипт
- smoke или тест
- запись в docs
