## 7) Copy QA Checklist

1. Нет абсолютов (`100%`, `гарантировано`, `без ограничений`).
2. Термин `VPN` допустим и используется единообразно в site + webapp + bot.
3. Везде одинаковые CTA: `Открыть оплату`, `Открыть кабинет`, `Перейти в бот`.
4. Start/Pro/Ultra описаны одинаково в site + webapp + bot.
5. Ошибки оплаты предлагают fallback в поддержку.
