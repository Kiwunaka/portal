# Admin Smoke: Кампания → Checkout → Активация (без реального списания)

Обновлено: `2026-02-15`

## Цель

Проверить, что путь кампании работает сквозным образом: deep-link контекст, checkout-ticket, создание заказа, метаданные в БД и корректные fallback-сообщения.

## Подготовка

1. Нужен админ-доступ к WebApp.
2. Нужен тестовый пользователь Telegram.
3. Нужен активный `campaign_key` и (опционально) `promo_code`.

## Шаг 1: Сборка ссылок

1. В `Промокоды` создать/проверить код.
2. В `Campaign/deeplink-конструктор` задать:
   - `campaign_key`
   - `promo_code` (опционально)
   - `plan_code=start_99`
   - `source=bot`
3. Сгенерировать и сохранить `bot_start_link`, `checkout_link`, `webapp_link`.

## Шаг 2: Проверка deep-link в боте

1. Открыть `bot_start_link` тестовым аккаунтом.
2. Проверить, что в оплатном сценарии контекст не потерян.
3. Проверить, что доступна кнопка `Открыть оплату ₽ (карта/СБП)`.

## Шаг 3: Проверка checkout контекста

1. Перейти по `checkout_link`.
2. Убедиться, что в интерфейсе видны:
   - `plan`
   - `campaign`
   - `promo` (если передавали)
   - `checkout_ticket: получен`
3. Если `checkout_ticket` отсутствует, убедиться в корректном fallback: переход в бот для привязки.

## Шаг 4: Проверка создания заказа

1. Нажать `Открыть оплату`.
2. Остановиться до реального списания.
3. Убедиться, что заказ создан и в UI видна разбивка:
   - база
   - скидка
   - итог

## Шаг 5: Проверка данных на backend

Проверить, что в `external_orders` появилась запись с:
1. `provider=freekassa`
2. `plan_code`
3. `campaign`
4. `promo_code` (если передавали)
5. `meta_json` с pricing breakdown.

## Шаг 6: Проверка пост-условий

1. Пользователь может вернуться в checkout без потери контекста.
2. В боте и WebApp нет конфликтующих сообщений о состоянии оплаты.
3. Ошибочные кейсы отдают понятные сообщения + путь в поддержку.

## Чек на выпуск

1. Контекст кампании сохраняется сквозным образом.
2. Нет ошибок создания заказа.
3. Нет неожиданных редиректов без ticket.
4. Текстовые подсказки соответствуют текущему copy-pack.

## Rollback

1. Отключить проблемный промокод.
2. Перегенерировать links с новым `campaign_key`.
3. Обновить пост в канале.
4. Повторить шаги 2-4 этого smoke-чеклиста.
