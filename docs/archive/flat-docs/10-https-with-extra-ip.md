# Как убрать порты `:8444` и `:2096` (вариант: доп. IPv4 на brain)

Проблема: на brain `:443` занят транспортом (Reality), поэтому сайт/ЛК/API/подписки сейчас живут на нестандартных портах (`:8444`, `:2096`). Это выглядит некрасиво и иногда ломает WebView.

Решение (вариант A): взять **дополнительный IPv4** на brain и посадить на него обычный HTTPS (Caddy) на `:443`.

## Итоговая схема

- `kiwunaka.space` -> **NEW_IP** (Caddy на `:80`/`:443`)
  - `/` маркетинг
  - `/app/` WebApp (ЛК)
  - `/api/*` Portal API
  - `/s8Kx2mP7qR4wT/*` подписки

- `de.kiwunaka.space` -> **OLD_IP** (Reality на `:443`), если ты хочешь использовать brain как DE-локацию

Важно: обычный браузер на `de.kiwunaka.space` не обязан показывать "SSL как у сайта", потому что там не сайт, а транспорт.

## Что нужно сделать руками (когда купишь IPv4)

1) У провайдера:
- добавь второй IPv4 на brain (NEW_IP) и прикрепи его к серверу

2) DNS:
- `kiwunaka.space A` -> NEW_IP
- (опционально) `de.kiwunaka.space A` -> OLD_IP

3) На brain:
- Caddy должен слушать **только NEW_IP:443**, чтобы не конфликтовать с Reality на OLD_IP:443.
  Пример (идея): в Caddyfile использовать `bind NEW_IP`.
- Portal API лучше проксировать через Caddy, чтобы он тоже был на `https://kiwunaka.space/...` без порта.

После этого:
- WebApp будет открываться как `https://kiwunaka.space/app/`
- Подписки будут как `https://kiwunaka.space/s8Kx2mP7qR4wT/<token>`
