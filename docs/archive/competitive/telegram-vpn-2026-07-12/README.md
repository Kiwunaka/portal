# Telegram VPN Research Snapshot

Snapshot date: 2026-07-12

Classification: `HISTORICAL_REFERENCE / ADVISORY`

This compact package preserves the useful conclusions from the former
`codex/vpn-competitor-infographics` workstream without promoting its code,
generated infographics, screenshots, or implementation suggestions into the
current product canon.

## Authority Boundary

- Use this material to answer why a direction was considered and what was
  observed in July 2026.
- Never use it to decide current product behavior, release state, routing,
  client recommendations, prices, bonuses, or runtime configuration.
- Reconcile every current action against the canonical owner in
  [docs/README.md](../../../README.md), current code/tests, and exact runtime
  evidence.
- The public `up to 10 days` wording means `5 trial days + 5 Telegram reward
  days`; it is not a `+10 day` Telegram grant for new accounts.
- Competitor recommendations such as Karing or Happ are historical
  observations, not the current POKROV client route.
