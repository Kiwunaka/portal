# Historical Notes And Archive

This directory marker exists to clarify how to read the older documentation set.

## What Is Historical

The following materials are still useful, but should not be treated as the first source of current truth:

- dated architecture snapshots
- audits
- postmortems
- old cleanup reports
- old rollout notes
- flat docs created before the current source-of-truth structure

## How To Use Older Docs

- use them for investigation, migration context, and forensic history
- do not use them as the only basis for changing current production logic
- if a historical file conflicts with the new canonical docs, update the historical file later or leave a note
