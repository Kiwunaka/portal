## 1) PL: текущий статус и гипотеза

Проверки с control-plane:

```bash
python scripts/remote_brain_network_probe.py
python scripts/remote_brain_nodes_sanity.py --brain-ip 82.21.114.104
python scripts/inspect_reality_inbound_remote.py --only pl --ssh-port 29374 --inbound-id 1
python scripts/inspect_reality_inbound_remote.py --only pl --ssh-port 29374 --inbound-id 2
python scripts/remote_inspect_brain_subscription_hosts.py --brain-ip 82.21.114.104 --domain kiwunaka.space
python scripts/audit_node_dns.py --domain kiwunaka.space --include-brain --out docs/audit-artifacts/dns_audit_20260208.json
```

Факты:

- `pl` порты `443/8443/29374` сейчас доступны.
- В `nodes` есть `pl` (`443`) и `pl_free` (`8443`), оба активны.
- Reality-параметры `pl` и `pl_free` консистентны (`sni=www.orange.pl`, одинаковый `pbk/sid`).
- В подписке присутствует `pl.kiwunaka.space`.
- DNS-аудит показал один и тот же `AAAA` для `pl/it/us`: `2a03:6f00:1::5c35:60df`.

Риск:

- При наличии IPv6 у клиента может выбираться общий `AAAA`, что даёт неверный endpoint для конкретной страны (в т.ч. PL) и приводит к нестабильным подключениям.

Рекомендированный фикс DNS:

1. Удалить общий `AAAA` для `pl.kiwunaka.space`, `it.kiwunaka.space`, `us.kiwunaka.space`.
2. Либо задать каждому поддомену его собственный IPv6-адрес соответствующей ноды.
3. Повторно прогнать `scripts/audit_node_dns.py` и проверить, что `shared_aaaa_across_different_nodes` исчез.
