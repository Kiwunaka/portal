# POKROV Public Beta PRD

Last updated: 2026-04-26

## Release Scope

Open Beta v4 is a preparation and gated-beta scope. It is not a `1.0.0` release and does not authorize broad public launch.

## User Promise

- App-first start remains the primary path.
- Trial duration is 5 days.
- Telegram linking can add +10 days when channel and account checks pass.
- Android and Windows are the active client tracks.
- Support and recovery remain available through the cabinet and official Telegram support bot.

## Public Limitations

- Android public release is blocked until signing and a physical release-build localhost/control-surface audit pass.
- Windows beta remains gated unless trusted signing and public handoff are verified.
- Paid checkout stays disabled or degraded until Lava.top evidence is attached.
- Direct public downloads stay hidden or support-routed until runtime handoff URLs are verified.
- iOS and macOS are not launch platforms for this wave.

## Launch Decision

Current decision: do not release publicly. See `docs/developer/work-orders/2026-04-open-beta-v4/13-launch-decision.md`.
