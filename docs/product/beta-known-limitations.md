# Beta Known Limitations

Last updated: 2026-04-26

- Public Android release is blocked by signing and physical release-build audit.
- Windows builds may remain unsigned and may trigger OS trust warnings.
- Direct download links can be unavailable for users without approved beta access.
- Paid checkout can be unavailable while Lava.top provider proof is missing.
- RU-origin reachability is a tracked dependency and must be tested separately.
- Support operates best-effort during beta with the cabinet and `@pokrov_supportbot` as official paths.
