# Руководство пользователя PORTAL VPN

Обновлено: 2026-03-19

## Что это такое

`PORTAL VPN` — приложение для `Android` и `Windows`, где основной сценарий максимально простой:

1. открыть приложение
2. нажать `Try free`
3. получить рабочий доступ
4. нажать `Connect`

## Что не нужно делать

На первом запуске пользователю не нужно:

- искать Telegram
- входить через Telegram
- вставлять ключ вручную
- импортировать ссылку подписки

## Бесплатный период

- базовый trial: `5 дней`
- бонус за Telegram: `+10 дней`

## Telegram в продукте

Telegram не обязателен для старта.

Он нужен только для дополнительных сценариев:

- получить бонус
- привязать аккаунт
- восстановить доступ
- получать новости и обновления

## Основные разделы приложения

- `VPN`
- `Locations`
- `Devices`
- `Profile`
- `Support`

## Поддержка

Пользователь может обратиться:

- из приложения
- через WebApp
- через helpbot: `@portal_privacy_helpbot`

## Важное текущее замечание

Механика бонуса за Telegram уже реализована в коде, но фактический публичный канал пока не доведён до рабочего состояния. Если бонус по каналу не срабатывает, это сейчас связано не с trial, а с конфигурацией канала.
