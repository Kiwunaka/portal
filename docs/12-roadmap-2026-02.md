# Roadmap 2026-02: Hybrid Checkout + Growth Funnel

Обновлено: `2026-02-14`

## Принятые решения

- Модель оплаты: `hybrid ₽ + Stars`.
- Новый план: `start_99` (`99₽`, `30 дней`, `1 устройство`, только `NL`).
- Free-логика: soft speed-bump для неподписанных на канал.
- Бонус за канал: `premium days + 100 points` (one-time points через campaign mark).
- Промо-ссылки: deep-link в бота + параметры в checkout (`promo`, `campaign`).
- Новости на сайте: 3 карточки `Live Updates` с deep links.
- Freekassa: 2 отдельные кассы (`site` и `bot`).

## Статус по потокам

### 1) Backend Payments

`Done`
- Добавлены Freekassa endpoint'ы:
  - `POST /api/payments/freekassa/orders/create`
  - `GET /api/payments/freekassa/orders/{order_id}`
  - `POST /api/payments/freekassa/orders/{order_id}/refund`
  - `GET /api/payments/freekassa/currencies`
  - `GET /api/payments/freekassa/currencies/{currency}/status`
- `POST/GET /api/payments/freekassa/notify`:
  - проверка SCI-подписи,
  - IP allowlist,
  - идемпотентный лог событий,
  - активация доступа после оплаты,
  - `YES` ответ на успешный `POST`.
- Раздельные env для 2 касс: `FK_SITE_*`, `FK_BOT_*`, `FK_NOTIFY_IP_ALLOWLIST`.
- Заказ связан с пользователем/планом через metadata (`tg_id`, `plan_code`, `campaign`, `promo_code`, `source`).

### 2) Bot + WebApp Funnel

`Done`
- Bot dual-pay CTA:
  - primary `Оплатить ₽`,
  - secondary `Оплатить Stars`.
- Deep-link промо:
  - `promo_<CODE>`,
  - `campaign_<KEY>__promo_<CODE>`,
  - авто-применение после `/start` и после accept TOS.
- WebApp:
  - dual checkout кнопки,
  - проверка подписки на канал (`/api/channel/subscriber/check`),
  - one-time `+100 points`,
  - отображение speed-bump статуса и причины.
- Speed-bump переведен в мягкий режим (без hard-block бесплатного доступа).

### 3) Marketing + Checkout UX

`Done`
- `marketing/src/app/checkout/page.tsx` переведен из mock в рабочий checkout:
  - Freekassa widget,
  - fallback-кнопка оплаты,
  - campaign/promo aware query-параметры.
- Визуал: kinetic typography + liquid glass.
- На главной:
  - блок про канал,
  - `Live Updates` (3 карточки, deep links),
  - убрана привязка к одному `TG_NEWS_POST_ID`.
