# Roadmap 2026-02: Payments + Growth Funnel + Docs

Обновлено: `2026-02-15`

## Цель релиза

За один цикл закрываем единый пакет:
- предсказуемый backend-first checkout в рублях,
- рабочие скидки для `RUB + Stars`,
- DB-backed админ-управление тарифами и Live Updates,
- обновлённый UX checkout/landing/WebApp,
- copy-pack для воронки,
- синхронизированные runbook и operator docs.

## Locked Decisions (фикс)

1. Первый релиз: полный пакет, не только docs.
2. Модель сайта: backend order first.
3. Guest без Telegram binding: ведём в бота.
4. Скидки: RUB + Stars.
5. Новости на сайте: admin-managed в БД.
6. Freekassa методы: `notify=POST`, `success/fail=GET`.
7. Политика Start/free: `Start 99 (NL, 1 device), free без дополнительного ужесточения`.
8. Цены: админ-управление в БД + формула экономики.
9. Deep links: platform-specific.
10. Публичный tone: консервативный, без абсолютных обещаний.
11. Post-payments roadmap: Retention + UI + Ops параллельно.
12. Секреты кассы: без ротации в этом цикле (принятый риск).
