# Stitch Mini Handover (Copy) 2026-02

Обновлено: `2026-02-15`

Цель: быстро перейти к дизайн-итерации в Stitch для 3 ключевых экранов, используя готовые текстовые блоки и ограничения по тону.

## Общие constraints

1. Язык: RU.
2. Тон: спокойный, premium-friendly, без жёсткого давления.
3. Нельзя: абсолюты (`100%`, `гарантировано`, `без ограничений`) и слово `VPN` в публичном copy.
4. Обязательные CTA: `Открыть оплату`, `Открыть кабинет`, `Перейти в бот`.

---

## Экран 1: Landing (Hero + Plans + CTA)

### Prompt block

Создай лендинг для сервиса PORTAL с акцентом на быстрый запуск и прозрачную оплату. Нужны блоки: Hero, преимущества, планы Start/Pro/Ultra, social-proof, FAQ и финальный CTA.

### Copy block

- Hero headline: `Стабильный доступ, который запускается за минуту`
- Hero subheadline: `Подключение через Telegram, продление в пару кликов и прозрачная сумма до оплаты.`
- CTA primary: `Открыть оплату`
- CTA secondary: `Перейти в бот`

Планы:
- Start: `30 дней • 1 устройство • NL`, note: `Мягкий вход для проверки сервиса в реальных задачах`
- Pro: `1 месяц • до 5 устройств • все страны`, note: `Сбалансированный вариант для ежедневного использования`
- Ultra/Family: `12 месяцев • до 5 устройств • полный пул стран`, note: `Долгий горизонт и предсказуемая цена на месяц`

### Disallowed copy

- `гарантированная скорость`
- `полная анонимность`
- `без ограничений`

## Экран 2: Checkout

### Prompt block

Сделай экран checkout с акцентом на доверие и прозрачность: выбор плана, контекст campaign/promo, блок социальной активности, понятные состояния ошибок и fallback в бот.

### Copy block

- Kicker: `[SAFE CHECKOUT FLOW]`
- Title: `PORTAL RUB CHECKOUT`
- Sub: `Заказ создаётся на сервере, затем открывается защищённая ссылка провайдера. Для оплаты нужен checkout ticket.`
- Warning (no ticket): `Для оплаты нужен checkout ticket. Откройте бота, завершите привязку и вернитесь в checkout.`
- Main CTA: `Открыть оплату`
- Fallback CTA: `Перейти в бот для привязки`
- Secondary CTA: `Канал проекта`
- Footer note: `После успешной оплаты статус продления обновится автоматически.`

## Экран 3: WebApp Status + Connect

### Prompt block

Сделай мобильный экран личного кабинета с двумя ключевыми секциями: `Статус` и `Подключение`. Упор на понятность первого запуска, прозрачную оплату и быстрый доступ в поддержку.

### Copy block

Статус:
- `Старт за 90 секунд`
- `Прозрачная разбивка: база, скидка и итог показываются до перехода на оплату.`
- `Проверить статус подписчика`
- `Канал проекта`

Подключение:
- `Для первого запуска: импортируйте ключ и нажмите «Проверить и завершить».`
- Android: `сначала deep-link, затем fallback`.
- iOS: `если схема недоступна, используйте ручной импорт по инструкции`.
- Desktop: `копирование ключа и импорт по документации`.
- CTA: `Проверить и завершить`
- CTA fallback: `Если не сработало: скопировать ключ`

## Definition of done для дизайн-итерации

1. Тексты легко читаются на мобильном и desktop.
2. Основные CTA видны без лишнего скролла.
3. Нигде нет запрещённых формулировок.
4. Start/Pro/Ultra и CTA совпадают с copy-pack из `docs/28-marketing-copy-pack-2026-02.md`.
